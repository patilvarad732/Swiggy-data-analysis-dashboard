# Swiggy Data Analysis Dashboard 📊

## 📌 Project Overview

This project focuses on analyzing Swiggy food delivery data using Microsoft Power BI. The interactive dashboard presents key performance indicators (KPIs), user performance, and city-level trends to support data-driven business decisions.

## 🎯 Project Objectives

- Analyze food delivery and order performance.
- Monitor key business metrics using KPI cards.
- Explore city-wise performance and trends.
- Present data through interactive charts and visualizations.
- Communicate meaningful insights to support business decisions.

## 🛠️ Tools & Technologies

- **Power BI** — Dashboard development and data visualization
- **Power Query** — Data cleaning and transformation, where applicable
- **DAX** — Calculated measures and KPIs, where applicable
- **Excel / Source Dataset** — Data preparation, where applicable

## 📊 Dashboard Pages

### 1. Main Dashboard
Provides an overview of the key metrics and trends available in the dataset.

### 2. City Overview
Presents city-level performance comparisons using the metrics and visualizations included in the report.

## 📈 Key Performance Indicators

The dashboard can be used to explore metrics such as:

- Total Orders
- Total Sales or Order Value
- User Performance
- City-wise Performance
- Other KPIs available in the report

*Note: The exact KPIs depend on the data and measures implemented in the dashboard.*

## 🔍 Project Workflow

1. Import the source dataset into Power BI.
2. Inspect and clean the data.
3. Transform data using Power Query, where required.
4. Create calculations and measures where needed.
5. Build interactive KPI cards, charts, and filters.
6. Analyze results and communicate business insights.
